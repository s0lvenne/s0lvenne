# Solven Vandermirant — сайт

Готовый статический сайт. Ни сборщиков, ни зависимостей: открыл `index.html` — работает.
Всё содержимое — **каждая надпись на сайте** — правится в одном файле: **`assets/content.js`**.

---

## Как менять тексты

Открываешь **`assets/content.js`** — там лежит каждая надпись, которая видна на сайте:
заголовок, подписи к цифрам, кнопки, описания проектов, вопросы, контакты, текст в
терминале, даже «Перейти к содержанию» и пасхалка.

Правила простые:

| Что хочешь | Что делаешь |
|---|---|
| Заменить фразу | Меняешь текст в кавычках, сохраняешь, обновляешь страницу |
| Перенос строки | Пишешь `\n` внутри текста |
| Добавить проект | Копируешь блок в массиве `projects.items` (внизу есть образец в комментарии) |
| Убрать раздел | Ставишь `enabled: false` у раздела — он исчезнет сам |
| Сменить цвета | Массив `accents` — цвет можно вписать любой, хоть `#00ff88` |
| Поменять аватар | Кладешь картинку в `assets/` и пишешь путь в `profile.avatar` |
| Своя ссылка | `meta.url` — домен для Open Graph |

Ничего, кроме этого файла, трогать не нужно: HTML и JS сами разберут, что где показывать.

### Если сайт перестал открываться

Значит, в `assets/content.js` опечатка. Сайт не останется пустым — покажет красную плашку
с объяснением, а точная строка ошибки будет в консоли (F12 → Console). Чаще всего это:

| Нельзя | Надо |
|---|---|
| `level: 50~` | `level: 50` |
| `level: ??` | `level: 50` или `level: null` (тогда вместо процентов будет «—») |
| `level: '50%'` | `level: 50` |
| пропущена запятая между пунктами | запятая после каждого, кроме последнего |
| незакрытая кавычка | кавычки парами |

Уровень навыка — **только число от 0 до 100** (или `null`, если уровень указывать не хочешь).

### Что ещё лежит в content.js

* `texts` — все служебные подписи интерфейса (кнопки, подсказки, сообщения об ошибках);
* `profile` — имя, дата рождения (возраст, часы и отсчёт до ДР считаются от неё automatically), строки карточки;
* `blackhole` — настройки внешнего вида чёрной дыры;
* `ui` — поведение: прятать ли шапку при скролле, показывать ли таймер сессии и т.д.

## Что было сделано

### Чёрная дыра (главное)
Старая версия была «нарисована в paint»: набор эллипсов, наклеенных друг на друга.
Теперь это настоящий рендер на WebGL:

* **трассировка фотонных геодезик** в метрике Шварцшильда — для каждого пикселя
  численно интегрируется уравнение `u'' = -u + 3/2·u²` (`u = 1/r`). Отсюда честное
  гравитационное линзирование: звёзды обтекают дыру, диск загибается **и над, и под**
  тенью, а фотонное кольцо получается само — его никто не рисует;
* **аккреционный диск**: кеплеровское вращение (внутренние слои быстрее внешних),
  турбулентность на fBm-шуме, температура `T ∝ r^(-3/4)` → цвет от белого у горизонта
  к красному снаружи, **доплеровский биминг** (приближающийся край заметно ярче) и
  гравитационное красное смещение;
* процедурное звёздное небо в equirect-карте 2048×1024 (генерируется при загрузке);
* дальние лучи считаются по точной аналитической формуле `α = 2rs/b` — это в разы
  дешевле и визуально неотличимо;
* постобработка: bloom (18 тапов по золотому углу), виньетка, плёночная тональная
  компрессия ACES, дизеринг против «бандинга»;
* **производительность**: адаптивное разрешение и число шагов по FPS, пауза при
  скрытой вкладке, учёт `prefers-reduced-motion`, лёгкий отклик на мышь;
* если WebGL нет — включается аккуратный фолбэк на Canvas2D с линзированием звёзд.

Фон (сетка) не тронут, как ты и просил, — добавлены лишь затемнение под текстом
и едва заметное зерно, чтобы градиенты не выглядели плоско.

### Удобство
* **Убрана «бомбёжка» адресной строки.** Раньше каждые 80 мс в URL писался
  случайный хеш — из-за этого не работали якоря и кнопка «назад». Теперь URL чистый.
* Настоящее мобильное меню: бургер с анимацией, закрытие по клику/вне/Esc,
  правильные `aria`-атрибуты (в старой версии кнопка была скрыта через `display:none`,
  поэтому на телефоне меню не открывалось вообще).
* Шапка прячется при скролле вниз и возвращается при скролле вверх; есть полоса
  прогресса чтения и кнопка «наверх».
* Копирование почты по клику + всплывающее подтверждение.
* Появление блоков при скролле (устойчиво к быстрому скроллю и переходам по якорям).
* Доступность: skip-link, видимый фокус, семантика, ловушка фокуса в модалке,
  поддержка `prefers-reduced-motion`, стили для печати.
* Счётчик посетителей больше не зависит от несуществующего GitHub-репо (раньше
  всегда показывал `?`): считает локально, а при желании можно указать любой API.
* Возраст, часы жизни и обратный отсчёт до дня рождения считаются из даты рождения.

### Содержимое
К старому (герой, «Обо мне», профиль, ссылки, проекты) добавлены разделы:
**Навыки**, **Путь** (таймлайн) и **Вопросы** (FAQ). Все они включаются/выключаются
в `assets/content.js` флагом `enabled: true/false` — ненужное просто убери или поставь `false`,
пункт меню исчезнет сам.

Также: переключатель акцента в шапке (красный / пустота / лёд / моно) — он же
перекрашивает чёрную дыру. Выбор запоминается.

## Структура

```
solven-site/
├── index.html            разметка (скелет, секции заполняются из конфига)
├── css/style.css         все стили, токены и темы
├── js/
│   ├── content.js        ← ВСЕ тексты, проекты, ссылки, настройки (правишь только его)
│   ├── blackhole.js      WebGL-шейдер чёрной дыры + Canvas2D-фолбэк
│   ├── main.js           сборка страницы, навигация, счётчики, модалки
│   ├── terminal.js       печатающийся текст
│   └── games.js          помощники для мини-игр (formatTime, saveRecord)
├── games/                clicker-enhanced.js, memory-game.js (пока не подключены)
└── assets/
    ├── favicon.svg
    └── avatar.png        ← сюда свой аватар
```

## Запуск

Локально — просто открыть `index.html`. Лучше через локальный сервер
(так корректнее работают шрифты и буфер обмена):

```bash
cd solven-site
python3 -m http.server 8000     # затем http://localhost:8000
```

Залить можно куда угодно: GitHub Pages, Netlify, Vercel, обычный хостинг.
Это статика, ничего собирать не нужно.

## Что поменять в первую очередь

1. **Аватар** — положи файл в `assets/avatar.png`. Пока файла нет, показывается
   сгенерированная заглушка с буквой S.
2. **`assets/content.js` → `meta.url`** — свой домен (используется в canonical и Open Graph).
3. **Тексты** — `about.paragraphs`, `timeline.items`, `faq.items`.
4. **Навыки** — цифры в `skills.groups[].items[].level` (это мои предположения, поправь).
5. **Проекты** — `projects.items[]`, можно добавлять сколько угодно.

## Подстройка дыры

`assets/content.js` → `blackhole`:

| параметр | что делает |
|---|---|
| `centerX` / `centerY` | положение на экране: `0` — центр, больше — правее/выше |
| `fov` | зум: меньше — дыра крупнее |
| `camDist` | расстояние камеры в радиусах Шварцшильда (18 — по умолчанию) |
| `incl` | наклон над плоскостью диска (0 — строго в торец, 0.17 — почти в торец) |
| `diskIn` / `diskOut` | внутренний и внешний край диска |
| `diskBright`, `starBright`, `bloom`, `halo`, `vignette` | яркость и постобработка |
| `haze` | яркость мягкой галактической дымки (0 — выключить) |
| `spin` | скорость вращения диска |

Звёзды рисуются процедурно прямо в шейдере, а не берутся из картинки: каждая —
кружок с краем ровно в полпикселя, поэтому они остаются круглыми и резкими при
любом разрешении и не «мерцают» при движении камеры. Текстура используется только
для едва заметной дымки (низкая частота — её сжатие не видно).
